Pre-built `.dictionary` bundle included as a release asset.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/brokosz/scottish-slang-dictionary/main/install.sh | bash
```

Or download `Scottish Slang.dictionary.zip` from Assets below, unzip, and copy to `~/Library/Dictionaries/`.

## What's included
- 450+ Scottish slang and jargon entries
- Compatible with macOS 26 (Tahoe)
- Works with Dictionary.app, three-finger tap lookup, and Spotlight
